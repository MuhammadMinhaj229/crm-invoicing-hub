# SAFAR N MANZIL

**Tell us what you need. We Do. We Assist. We Connect.**

Gulf assistance and local coordination for families in India — one public
website and one team console, sharing one database.

## What is inside

- A public website whose every word and picture is edited from the console.
- Visitor tracking that belongs to you alone, with no outside tracker.
- Leads, customers, one timeline per person, and churn watching.
- One inbox for WhatsApp and social messages.
- Invoices, payments, expenses and what partners are owed.
- Services, prices and answers written down once and used everywhere.
- Rules that do small jobs for you, with every run recorded.

## Getting started

```sh
bun install
bun run dev
```

Then open the console, go to **Settings → Connections**, paste your own
Supabase URL and public key, and run the setup script in your Supabase SQL
editor. Copy `.env.example` for anything that needs server-side keys.
